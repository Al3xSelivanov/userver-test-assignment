# Скрипт для воспроизведения замеров времени компиляции userver-сервиса

Запуск из этой папки:

```bash
./run.sh
```

Каждый запуск создаёт новую папку для результатов - `results/run-.../` и печатает её
полный путь в начале и конце. 

Производится несколько разных замеров, время работы скрипта может занять 10-15 минут.

Сырой вывод Clang Build Analyzer для каждой сборки находится по адресу вида `results/run-.../runs/scenario-variant-N`, где scenario - сценарий сборки (см. отчёт), variant - версия проекта (baseline - исходный, optimized - измененный для проверки гипотезы), N - номер сборки.

Файлы с сырым выводом Clang Build Analyzer и summary.md моего локального запуска, на которые ссылается отчёт, лежат в `local_result/`
